# Nicolai invitation widget

This branch contains the verified wave-only widget, delivered here because the chat artifact downloads failed.

- **Nicolai-Wave-Widget.zip** — ready-to-use browser bundles, standalone demo, and editable source.
- **Nicolai-Wave-Demo.html** — self-contained demo; download and open it in your browser.
- **Nicolai-Wave-Preview.mp4** — six-second close-up preview.

Open a file on GitHub and choose **Download raw file**. The ZIP contains installation instructions. The destination link remains the configurable placeholder `#game`.

The approved original character and full-size sleeve are fixed; only the original hand makes one relaxed 1.6-second wrist wave. All 14 browser checks passed, including desktop/mobile, links, reduced motion, and unchanged head, sleeve, torso, and outline pixels. The packaged source rebuilds the exact delivered files.

SHA-256 checksums are in `SHA256SUMS.txt`.
