# Asset choices — version 1.14

Open index.html locally or through the repository server. No dependencies.
A preserves the previous actual sprites. B–E propose four new city directions
and four new park bench/branch directions. None is integrated into gameplay.
The two native atlases are in art/. manifest.json records integer extraction
bounds; crops retain native pixels and use lossless WebP. Original baseline
art remains unchanged in the main assets directory.

The page shows both detail and an approximate gameplay-scale comparison.
Final bounding-box registration, typography and movement belong to the next
pass after the user chooses. A city/park choice is copied as text for the chat;
the page cannot change the game. Backgrounds are references only.
